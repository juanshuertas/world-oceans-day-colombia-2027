# 05 — Blue Standard Oceanic Global

## Objetivo

Obtener y sostener la certificación **Blue Standard de 3 Estrellas** para todas las sedes del programa.

## Checklist de auditoría

- [ ] Inventario de proveedores y sedes.
- [ ] Política institucional cero plásticos de un solo uso.
- [ ] Prohibiciones y sustitutos aprobados.
- [ ] Sistema Punto Verde/SWAP activo.
- [ ] Compras con criterios circulares y trazables.
- [ ] Gestión de residuos por peso y fracción.
- [ ] Personal y voluntariado capacitado.
- [ ] Abastecimiento de agua reutilizable.
- [ ] Proveedores firmantes y monitoreados.
- [ ] Evidencia foto, geográfica y documental por sede.
- [ ] Plan correctivo y responsable de cierre.
- [ ] Solicitud formal y auditoría Oceanic Global.

## Blue Summit Playbook Colombia 2027

El playbook debe contener:

1. Principios y alcance de las 3 Estrellas.
2. Matriz por sede y responsable.
3. Lista de materiales prohibidos y alternativas.
4. Operación Punto Verde/SWAP.
5. Auditoría previa, días de evento y post-control.
6. Evidencia mínima y registro de hallazgos.
7. Escalamiento de incumplimientos.
8. Continuidad para el Mes de los Océanos.
9. Plantilla de reporte y comunicación.
10. Plan de legado y extensión a eventos aliados.

## Criterios de aceptación

- Autodiagnóstico aprobado por sede.
- Hallazgos críticos cerrados antes del 1 de junio.
- Auditoría 3 Estrellas completada por Oceanic Global.
- Playbook versionado y publicado en el repositorio.
